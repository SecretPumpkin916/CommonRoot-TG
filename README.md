## What is TG?

TG is a minimal formal symbolic system built from scratch. It starts from a single **Root (K)** and, through two axioms, derives ten results that touch on identity, existence, consciousness, and the observer.

Unlike ZF-based approaches that encounter logical "explosions" when confronting self-referential totality, TG absorbs the explosion and continues — by treating every contradiction as a derivative of the same root.

## Key Results

1. **Common Root** — All derivatives converge to one at the root, returning to zero.
2. **Consciousness Must Exist** — K needs an observer (&) to collapse into existence.
3. **The Root-Trace Diagram Cannot Be Drawn** — Whether by the S path or the !S path.
4. **There Is Nothing Absolute** — null and unll do not exist in an absolute sense.
5. **All Derivatives Are Observers** — & = Ψ.
6. **All Is Ψ. All Is K.** — Everything in the real world is both observer and root.
